Machine Learning
------------------
It is the process of teaching computers to learn patterns from data & make decisions  based on those patterns.

-> Training Process  : Computers to learn patterns from data

-> Inference: Make decisions based on those patterns.

 * Difference between Algorithm & Machine Learing Algorithm


   Input                |    Input Data  & Expected Output
    ↓                   |                 ↓ 
  Logic / Rules         |            ML Algorithm
    ↓                   |                 ↓
  Output                |            Trained Model
                        |                  ↓
                        |            Prediction


ML Example – Loan Approval
--------------------------------
Suppose a bank wants to decide whether a loan should be approved or rejected.
- Input: Applicant information such as income, credit score, employment, loan amount, etc.
- ML Model: The model learns patterns from previous applicants and their loan decisions.
- New Input: Information of a new applicant is given to the trained model.
- Output: The model predicts “Loan Approved” or “Loan Rejected.”
Flow:
Applicant Information → Trained ML Model (Learned Logic) → Prediction → Loan Approved/Rejected

Conclusion:
- ML learns from past data & uses that learning to make prediction for new data.

Types :
- Supervised Learning
- Unsupervised Learning
- Reinforcement Learning
