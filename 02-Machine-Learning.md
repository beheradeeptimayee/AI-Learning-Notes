Machine Learning
------------------
It is the process of teaching computers to learn patterns from data & make decisions  based on those patterns.

-> Training Process  : Computers to learn patterns from data

-> Inference: Make decisions based on those patterns.

* * Difference Between Algorithm & Machine Learning Algorithm

### (i) Traditional Algorithm

| Step | Process |
|---|---|
| Step 1 | **Input** – Give the required input |
| Step 2 | **Logic / Rules** – Programmer defines the rules |
| Step 3 | **Processing** – Rules are applied to the input |
| Step 4 | **Output** – Final result is produced |

**Flow:**

`Input → Logic / Rules → Processing → Output`


### (ii) Machine Learning Algorithm

| Step | Process |
|---|---|
| Step 1 | **Input Data** – Provide training data |
| Step 2 | **Expected Output** – Provide the correct/known results |
| Step 3 | **ML Algorithm** – Learns patterns from the data |
| Step 4 | **Training** – Model learns the relationship between input and output |
| Step 5 | **Trained Model** – Learned patterns are stored in the model |
| Step 6 | **New Input** – Give new/unseen data |
| Step 7 | **Prediction** – Model predicts the output |

**Flow:**

`Input Data + Expected Output → ML Algorithm → Trained Model → New Input → Prediction`

Types:-
-------------
- Supervised Learning
- Unsupervised Learning
- Reinforcement Learning

Conclusion:
- ML learns from past data & uses that learning to make prediction for new data.
