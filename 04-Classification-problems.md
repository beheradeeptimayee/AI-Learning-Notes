-Used when the output is a category /class
***for example:
Email->Spam/not Spam
Loan->Approved/Rejected
Disease detection->Disease/No disease

***Classification can be :
- Binary Classification
- Multi-class Classification

(i)Binary Classification: Only 2 classes
Ex: Spam/Not Spam

(ii)Multi-class Classification: More than 2 classes
Ex: Email->Spam/Promotion/Social/Primary

***Some Classification Algorithms
----------------------------------
| Algorithm | Main Idea |
|---|---|
| Linear Classifiers | Separate data into classes using a linear decision boundary. |
| Logistic Regression | Predicts the probability of a class, commonly used for binary classification. |
| K-Nearest Neighbours (KNN) | Classifies new data based on the labels of its nearest neighbours. |
| Support Vector Machine (SVM) | Finds a decision boundary that separates classes with the largest possible margin. |
| Random Forest | Combines multiple decision trees to make a classification prediction. |
| XGBoost | Builds decision trees sequentially, with each new tree helping correct previous errors. |
