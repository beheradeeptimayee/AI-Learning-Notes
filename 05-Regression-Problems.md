- The Problems where at the end  we try to predict a numeric output.
Ex: House details-->House price=50 Lakh
 Years of experience-->Salary=50k

***Flow:
Input/Features(x)--->RegressionModel-->NumericalOutput(y)

***Some Regression Algorithms
-------------------------------
| Algorithm | Main Idea |
|---|---|
| Linear Regression | Fits a straight-line relationship |
| Multiple Linear Regression | Uses multiple input features |
| Polynomial Regression | Fits curved relationships |
| Ridge Regression | Reduces large coefficients |
| Lasso Regression | Can eliminate less useful features |
| Decision Tree Regression | Learns decision-based splits |
| Random Forest Regression | Combines multiple trees |
| Support Vector Regression (SVR) | Fits within an error tolerance |
| Gradient Boosting Regression | Corrects errors sequentially |



**Difference between Classification & Regression.

| Classification | Regression |
|---|---|
| Predicts category | Predicts number |
| Spam/Not Spam | House price |
| Cat/Dog | Salary |
| Pass/Fail | Temperature |
| Fraud/Not Fraud | Sales |
